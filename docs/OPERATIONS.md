# 数据、运行和维护

## 目录

- `engine/`：API、任务调度、模型路由（`llm.py`）、记忆（`memory.py`）、技能、MCP、智能家居连接器（`home/`）、工具、代码工作台、媒体工作流。
- `web/`：网页版（PWA）。
- `native/Sources/`：共享的 SwiftUI 界面、TLS 客户端、钥匙串和扫码。
- `config/`：固定的依赖版本、运行时来源、扩展校验清单。
- `data/jurvis.sqlite3`：对话、任务、素材索引、分镜、记忆、设备和代码项目。
- `data/assets/`：生成媒体；`data/coding/`：代码修改快照；`data/logs/`：运行日志。
- `data/settings.json`：默认模型、记忆和家居的偏好；`data/skills/`：技能。
- `data/personal.json`、`data/backup.json`、`data/portrait-cloud.md`：日历与通讯录的开放范围、备份设置、给云端模型的画像；`data/backups/`：每晚的备份。
- `data/security/`：设备本地令牌和 TLS 私钥，以及模型服务的 API Key（`providers.json`）、MCP 服务（`mcp.json`）、家居连接器的令牌（`home.json`）、邮箱的令牌和专用密码（`mail.json`）、推送密钥（`push.json`）；整个 `data/` 默认仅当前用户可访问，不应上传到仓库。

## 运行

引擎监听 TLS 18777；MLX 和 ComfyUI 分别只监听本机 18778/18779。本机模型串行切换以控制内存。选择云端模型时，对话内容（包括附带的图片、取回的记忆和工具结果）会发送给所选的服务；本机模型不发送任何内容。退出 Mac 界面后已启动的引擎可继续处理移动端任务。

## 备份与安全边界

引擎每晚自动备份数据库、设置、密钥、笔记和工作区文档到 `data/backups/`（可改到另一块硬盘），不需要停引擎；内容、恢复步骤和注意事项见[备份](REACH.md#备份)。想手动整体备份（包括生成的媒体），先停止引擎，再复制整个 `data/`。代码撤销仅在文件仍与本次应用后的版本一致时执行；其他编辑器的更新会触发冲突提示。代码执行和助手的命令直接在本机运行，没有容器沙箱；助手命令以你的用户身份、无标准输入运行，不会自动提交、推送或发布。
