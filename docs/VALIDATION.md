## 本地模型与 Coding

- Qwen 3.8 27B MLX：真实载入并完成对话、计算工具调用、分镜规划、视频提示编排和代码修改建议。
- 计算任务：`(128+64)*3` 得到 `576`。
- Coding 验收项目：`data/acceptance/Coding验收`。模型读取包含错误的 `calc.py` 与测试，将加法函数的 `a*b` 改为 `a+b`，在差异审阅后应用；项目 pytest 实际执行结果为 `1 passed`。
- 代码任务：`0894d2a40bfa425daf5dce505b4307b5`。测试任务：`3044f81adec942819ec681ea59b4e540`。
- 自动化测试另外验证：拒绝目录穿越/符号链接，拒绝修改未读的已有文件，应用前检测外部编辑冲突，撤销不覆盖后来的编辑，失败测试保留输出并呈现失败。

这些结果证明首版的基本编码闭环可运行；不代表已经评估大型仓库、多文件重构和复杂工程的模型正确率。项目脚本当前在 Mac 上执行，没有容器沙箱。
